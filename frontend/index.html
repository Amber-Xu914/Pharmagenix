About Pharmagenix

Pharmagenix helps researchers and students explore how drugs and genes interact: which drugs inhibit, induce or bind a gene's product, which genes metabolise a drug, and how genetic variants change a patient's response.

Each search combines curated reference datasets (HGNC, ChEMBL, CPIC and the Australian PBS Schedule) with live evidence from DGIdb, PharmGKB/ClinPGx, PubTator3 and DrugBank. A large language model then writes a summary in which every claim cites its evidence. The table and network are built directly from the source data, never by the model.
