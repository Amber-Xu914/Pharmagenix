Notes:

- Citation validity: grounded arms cite evidence IDs, checked against the IDs in the prompt; the ungrounded arm cites PMIDs, checked against PubMed. A real PMID can still be about something else: see *Real PMIDs on topic*.
- Drugs not in the evidence: drugs the report names that no evidence record of the case names. For the ungrounded arm this measures claims the curated sources do not back, not necessarily false ones.
- Expected answer recall: VCF cases use the expected established drugs of `evaluation.CASES`; gene / drug cases use CPIC level A pairs and FDA-label facts (`benchmark.GOLD`).
- VCF cases where nothing is tiered are skipped: the deployed system writes no LLM report for them.
